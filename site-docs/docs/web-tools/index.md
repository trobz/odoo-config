# Web tools

Browser pages built on the [schema](../reference/schema.md). No install
needed.

## Option lookup

Every option odoo-config knows about, with its default in each Odoo
version from 12.0 to 20.0 and the Trobz-tuned values on top.

[Open the option lookup](odoo-option-lookup/)

## Version matrix

How options appear, disappear, and change their default between Odoo
versions. Pick two versions to see what changes when you migrate.

[Open the version matrix](odoo-option-matrix/)

## Config builder

Pick a version, preset, and edition to see the exact config file
`odoo-config create` writes, plus the command to run.

[Open the config builder](odoo-conf-builder/)
